角色像素素材来源与授权
========================

本目录下所有 PNG 均由 UnitForge Sample Sprite Pack 切片而来。

- 来源：https://opengameart.org/node/192815 （Pixel Chibi Character Pack）
- 作者：UnitForge（https://unitforge.net）
- 授权：CC0 1.0 Universal（公有领域）
  - 可商用、可修改、无需署名
  - 不可将素材本身作为独立素材包转售

原始规格
--------
- 每帧 48×48 px，每行 8 帧
- 行序：IDLE / MOVE / ATTACK / [武器专属攻击] / DAMAGED / DEATH
- 锚点：底部居中，地平线位于帧底上方 6px

本项目的切片
------------
- hero_idle.png    knight 第 0 行（IDLE）8 帧
- hero_move.png    knight 第 1 行（MOVE）8 帧
- hero_attack.png  knight 第 2 行（ATTACK）8 帧
- mob_idle.png     gunner 第 0 行（IDLE）8 帧
- mob_move.png     gunner 第 1 行（MOVE）8 帧
- mob_death.png    gunner 第 5 行（DEATH）8 帧

切片方式：按 48px 网格横向裁切，保持透明通道与像素锐利度
（渲染时使用 image-rendering: pixelated）。


程序化生成的站点素材（新增）
----------------------------
以下 PNG 由本项目脚本 tools/gen_pixel_assets.py 程序化生成，
为原创作品，同样以 CC0 1.0 释出，可自由使用与修改。

- bg_brick.png     96×96  地牢砖墙，无缝平铺（受 2D 光照层影响）
                   生成约束：tile % bw == 0 且 (tile // bh) 为奇数，
                   否则平铺后横缝会连成贯穿直线。
- bg_plate.png     32×32  UI 面板底纹，无缝平铺（不受光照）
- frame_panel.png  24×24  九宫格金框，slice 8；可拉伸边为纯色环带，
                   角部铆钉不参与拉伸，故任意尺寸下不变形。
- frame_card.png   12×12  九宫格石板框，slice 4
- frame_tip.png    12×12  九宫格金框（提示框），slice 4
- badge_star.png   32×32  像素星级徽章，替代 ★ 字形

重新生成：python tools/gen_pixel_assets.py
自检（无缝 / 九宫格拉伸）：python tools/_verify_assets.py
